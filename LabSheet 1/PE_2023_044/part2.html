    Protocol Definitions

    TCP
    Transmission Control Protocol; a connection-oriented protocol that guarantees packet delivery.
    UDP
    User Datagram Protocol; provides fast, connectionless transmission without error recovery.
    HTTP
    Hyper Text Transfer Protocol; enables the exchange of hypermedia documents across the web.
